HUMANO benchmark guide

HUMANO evaluates generalist humanoid loco-manipulation across 100 tasks in eight suites.

Explore demonstrations

Open the Task Explorer, select a suite or task, and switch between available configurations and camera views.

Download a task

Choose a suite and task in the HUMANO dataset on ModelScope. Each task ZIP contains training demonstrations, evaluation episodes and their frozen placements. Follow the download and extraction guide to install it under data/.

Evaluation

The leaderboard compares in-distribution task performance and out-of-distribution robustness. The HUMANO-Plus examples illustrate the seven distribution shifts.

For installation and execution instructions, see the README and docs directory in the HUMANO benchmark repository.
