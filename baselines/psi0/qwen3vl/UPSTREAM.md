# Qwen3-VL Processor Resources

The files in this directory are the configuration, tokenizer, chat template,
and image/video processor metadata from `Qwen/Qwen3-VL-2B-Instruct` at revision
`89644892e4d85e24eaac8bacfd4f463576704203`.

They do not contain Qwen model weights. They are retained so HUMANO can build
the processor and model architecture offline before loading the Psi0 checkpoint.

Upstream model card: <https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct>
